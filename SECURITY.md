# Security Policy

## Supported Versions

The following versions of Lumina currently receive security updates:

| Version | Supported |
| :--- | :--- |
| `1.0.x` | Yes |
| `< 1.0.0` | No |

## Reporting a Vulnerability

We take the security of Lumina seriously. If you discover a security vulnerability, please report it responsibly instead of opening a public GitHub issue.

### Preferred Disclosure Method

Submit a private vulnerability report via GitHub:
- [Submit a Security Advisory](https://github.com/AtaCanYmc/lumina/security/advisories/new)

### Alternative Method

If private advisories are unavailable, email the maintainer directly at [atacanymc@gmail.com](mailto:atacanymc@gmail.com) with the subject line:
`[SECURITY] Vulnerability in lumina-tools`.

Please include in your report:
1. A description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal proof of concept.
3. Affected software version and runtime environment.

### Response SLA

- **Initial Acknowledgement**: Within 48 hours of receipt.
- **Triage and Assessment**: Within 5 business days.
- **Remediation and Release**: Coordinated fix release published as soon as verification is complete.
